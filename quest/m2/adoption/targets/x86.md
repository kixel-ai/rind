# [XS] rind on 32-bit x86 at the MSRV

## Goal

rind and rind-rustls build for 32-bit x86 (`i686`) on the workspace's 1.90 MSRV, as they do on every other target, so [PLATFORMS.md](/PLATFORMS.md) and the README drop their 1.94 exception.

## Plan

CI already tests i686 Linux, Windows, and Android on stable. Only libcrux-platform 0.0.4 needed Rust 1.94 there ([celabshq/libcrux#1646](https://github.com/celabshq/libcrux/issues/1646)), and rind no longer depends on it: libcrux-aes, which pulled it in, went with [portable AES-GCM's rework](https://github.com/moq-dev/rind/pull/613). Check i686 in `sh/dispatch.sh`'s `msrv` module (adding the target to the flake's `msrv` shell), and drop the exception.
