# [M] rind on 32-bit x86

## Goal

rind and rind-rustls build for i686-unknown-linux-gnu, i686-pc-windows-msvc, i686-linux-android and i586-unknown-linux-gnu on the [portable backend](/quest/m2/adoption/targets/portable.md), and CI runs the test suite (Wycheproof, differential, rind-rustls handshakes) under qemu on each.

## Plan

Android x86 and 32-bit Windows are the likeliest consumers. aws-lc has x86 assembly, but it's out of scope until a consumer measures a need. A missing CPU feature still fails with an error naming it; the portable backend needs none. Add the targets to [PLATFORMS.md](/PLATFORMS.md) and the release checks in the same PR.

## Required

- [Portable backend](/quest/m2/adoption/targets/portable.md) - the backend these targets compile
