# [S] x86_64 SHA-256 of 64 B messages as fast as ring

## Goal

SHA-256 of a 64 B message on x86_64 with the SHA extensions matches ring. It reads 1.09-1.19 on the Zen 4 and Zen 5 runners, while rind leads at 32 B and is level from 1200 B.

## Plan

Planned with the maintainer on 2026-11-03 from the speed-gap audit (runs 41552375686, 41550707545, 41550703300, 41522483267).

- Bulk speed is level, so the cost is in finishing the message, not the block function. [moq-dev/rind#255](https://github.com/moq-dev/rind/pull/255) defers the last block, so a 64 B message is copied into the `Blockwise` buffer and again into `last` before compressing 128 B; ring compresses the block straight from the caller's input.
- Compress whole blocks from the caller's slice and copy only the tail and padding. Keep #255's single call wherever it measures faster (SHA-1, SHA-512, aarch64).
- Measure on the Zen 4 and Zen 5 runners, not the local hosts.
